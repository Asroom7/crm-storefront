## قانون قفل سکشن‌ها

1. هر سکشنی که تأیید شده، قفل محسوب می‌شود.
2. اگر درخواست فقط مربوط به یک سکشن/کارت/کنترل است، فقط همان محدوده باید تغییر کند.
3. ترتیب سکشن‌ها، CSS عمومی، DOM عمومی، Runtime مشترک، منطق داده و فایل‌های مشترک نباید برای یک تغییر محلی دست‌کاری شوند.
4. اگر انجام درخواست واقعاً نیازمند تغییر فایل یا Runtime مشترک باشد، کار باید متوقف شود و قبل از تغییر، محدوده‌ی اثر به‌صورت دقیق مشخص و از کاربر اجازه گرفته شود.
5. تغییرات جدید ابتدا روی branch کاری جدا انجام می‌شوند، نه مستقیم روی `stable-approved`.
6. قبل از انتشار، باید علاوه بر تست بخش جدید، بررسی شود که سکشن‌های قفل‌شده نسبت به نسخه‌ی قبل تغییر نکرده‌اند.
7. حذف یا بازنویسی یک سکشن تأییدشده برای ساده‌تر کردن پیاده‌سازی ممنوع است.
